A little context

Readable mode produces sections, paragraphs, lists, links and reusable commands that you can edit normally. Copy the source into Overleaf and compile with pdfLaTeX.

Document structure is inferred and text reflows after edits. Review tables and equations. For a closer visual copy, choose Preserve original layout. Scans can be retained as images in Preserve original layout mode.

Files stay on this server and are not saved by the app.
