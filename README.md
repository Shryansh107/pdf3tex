# pdf3tex

pdf3tex is a project for exploring conversion from PDF documents to TeX source. The repository currently contains only its initial project scaffold; PDF parsing and TeX generation are not implemented yet.

## Status

This project is at the starting point. There is no runnable application, command-line interface, or test suite yet.

- `assets/icon.svg` — project icon
- `README.md` — project overview
